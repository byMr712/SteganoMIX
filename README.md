# SteganoMIX

**SteganoMIX** — приложение для стеганографического сокрытия и извлечения информации (текстовых сообщений и произвольных файлов) в 24-битных изображениях формата BMP с поддержкой криптографически стойкого псевдослучайного рассеивания пикселей (Seed Scattering) и избыточного дублирования служебных заголовков.

---

## 🚀 Ключевые возможности и архитектура

### 1. HVS-оптимизированное распределение бит по каналам RGB
Распределение бит учитывает психофизиологическую модель зрительного восприятия человека (**Human Visual System**):
- **Зеленый канал (G)** воспринимается человеческим глазом с наибольшей чувствительностью (~59% воспринимаемой яркости $Y$).
- **Красный канал (R)** — умеренная чувствительность (~30%).
- **Синий канал (B)** — наименьшая чувствительность (~11%).

| Уровень упаковки | Байт/пикс | Бит/пикс | Канал Red (R) | Канал Green (G) | Канал Blue (B) | Описание |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **Уровень 1** | 1 | 8 | 3 бита (0..2) | **2 бита** (3..4) | 3 бита (5..7) | Наилучшее визуальное качество, минимум шума в G |
| **Уровень 2** | 2 | 16 | 5 бит (0..4) | 5 бит (5..9) | **6 бит** (10..15) | Баланс между емкостью и визуальными искажениями |
| **Уровень 3** | 3 | 24 | 8 бит (Байт 0) | 8 бит (Байт 1) | 8 бит (Байт 2) | Максимальная емкость контейнера |

---

### 2. Безопасность и псевдослучайное рассеивание (Seed-based Scattering)
- Генерация криптографически стойкого начального значения (Seed) с использованием аппаратного источника энтропии (`std::random_device`, `QueryPerformanceCounter`, `GetTickCount64`, Murmur3 Finalizer).
- Псевдослучайное распределение полезной нагрузки по пикселям изображения по алгоритму частичного тасования Фишера-Йетса ($O(\text{count})$).
- Извлечение информации без знания точного Seed математически невозможно.

---

### 3. Двойное дублирование служебных заголовков и отказоустойчивость
- **Первичный заголовок**: столбец 0 (`x = 0, y = 0..N`).
- **Дублирующий заголовок**: последняя строка (`y = height - 1, x = 0..N`).
- При повреждении или зашумлении одного из заголовков система автоматически восстанавливает метаданные из резервной копии.

---

### 4. Поддержка встраивания произвольных файлов (File Mode)
- Возможность внедрять в BMP любые бинарные файлы (`.zip`, `.pdf`, `.bin`, `.docx` и т.д.) с сохранением исходного расширения.
- Автоматический просмотрщик/экстрактор позволяет как читать текст, так и выгружать бинарные файлы обратно в директорию `output_img/`.

---

### 5. Автоматизированный тестовый комплекс (Diagnostic Suite)
Встроенный набор автоматических тестов для валидации обратимости бит, отказоустойчивости, шифрования и граничных условий:
```cmd
Steganografia.exe --test
```

## 🛠 Сборка проекта

### Требования:
- Visual Studio 2022 (MSVC v143) с поддержкой C++20
- Windows SDK 10.0+
- GDI+ (`gdiplus.lib`)

### Сборка через MSBuild:
```cmd
msbuild Steganografia.sln -p:Configuration=Release -p:Platform=x64
```
